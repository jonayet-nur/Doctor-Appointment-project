# 🏥 Doctor Appointment Booking System

A full-stack Doctor Appointment Booking platform that allows patients to schedule appointments with doctors through a modern and responsive web application. The system provides seamless appointment management with features like booking, updating, and deleting appointments while maintaining a clean user experience.

---

# ✨ Key Features

## 📅 Appointment Booking

Patients can easily book appointments by selecting doctor details, preferred date, time, and providing personal information.

## ✏️ Appointment Management

Users can update existing appointment information without reloading the page using dynamic modal-based forms.

## ❌ Secure Appointment Deletion

Appointments can be deleted safely with confirmation alerts to prevent accidental removal.

## 📱 Responsive Modern UI

Fully responsive dashboard and user interface optimized for desktop, tablet, and mobile devices.
